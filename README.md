# Makowski Sad Website

## Description

Just a simple website for a company that sells natural juices.

## Table of Contents

- [Installation](#installation)
- [Usage](#usage)
- [Contact](#contact)

## Installation

Just clone and open the project in VS/Cursor.

## Usage

- run in dev container
- execute `npm run dev`

The css custom file `src/input.css` contains some debugging features like styling elements with border. This has to be removed before building the project for production.
