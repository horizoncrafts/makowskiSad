# Build the anime version

Build a Makowski Sad version as an anime telling of the orchard. The folder is `versions/YYYY-MM-DD-anime/`.

Cel-shaded sky gradients and layered SVG silhouettes of the Beskidy hills behind the photos. Wind and petals. A lens-flare glow matched to the backlit photos. A title card for each chapter. Light moves from spring morning to autumn evening.

Done when the golden-hour mood of the photos is there and the seasons read as time passing. Nothing flashes more than 3 times a second.

Follow `versions/PLAN.md` for every shared rule.

## Done

Built by Claude on 2026-10-14 in `versions/2026-10-14-anime/`: eight episodes, each with its own cel-shaded sky over the same Beskidy ridges, from a spring morning to an autumn evening. Lens flares sit on the measured sun of the ten backlit photos. Only the drive and the press are drawn, both labelled as illustrations. Lighthouse mobile on a gzip static server: performance 97, accessibility 100. No sideways scroll from 320 to 1920 px.
